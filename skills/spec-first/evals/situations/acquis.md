## Comment ils sont tirés des résultats
Ces deux versions ont été jouées avant les trois passages, et la 1.8.0 ne nomme pas les points ratés.
- Réussi = « oui » ; « partiel » compte comme raté.
- 1.9.0 : le second passage (« Après corrections »), celui du SKILL livré ; le premier ne compte pas.
- 1.8.0 : les réponses « a », sauf 12, 23 et 24, rejouées (« b ») après une correction du SKILL faite pendant le banc : seule la b compte (dernière notation).
- Points ratés : ceux que le fichier nomme ; sinon la colonne « Ce qui a été mal compris », rapprochée de la grille. Contrôle : les points ratés rendent compte des points perdus (20,5 sur les réponses a de la 1.8.0, et chaque réponse b ; 10,5 au second passage 1.9.0).
- « déduit » : l'écart décrit ne nomme pas le point sans ambiguïté, ou n'explique pas tous les points perdus ; l'attribution retenue est dans la colonne « Note ». Le prochain passage, à trois réponses, tranche.

Les points seulement réalignés sur D15 (même conduite, autres noms : `baseCommit` de la revue, « revue » pour « contrôle strict », suite complète dans la revue) gardent leur historique.
